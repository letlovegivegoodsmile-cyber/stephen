Demandes de réservation

Les formulaires envoyés sont enregistrés dans Netlify. Connectez-vous au compte Netlify qui héberge ce site pour les consulter.

Ouvrir Netlify
  1. Dans Netlify, sélectionnez le site de votre projet.
  2. Ouvrez la section Forms, puis le formulaire event-booking.
  3. Pour recevoir un email à chaque demande, configurez une notification de formulaire dans les paramètres du site.
